# Opt1 1.0.8

## What's new

- Overhauled the UI for simple clues so you now have the most important information front and centre.
    - Added emote guidance and equipment information for emote clues.
    - Added hidey hole information for emote clues.
    - You can now mark a hidey hole as filled so you don't have to remember yourself.
    - Cryptic clues are instruction-first.
    - Challenge scroll answers now appear in the UI for the clue instead of having to press Opt+1 again to get the challenge scroll answer.
    - The UI now warns you if you should beware of double agents.
    - Coordinate clues now show dig info before reiterating the coordinates.
    - Closest teleport now shows the two closest teleports.
    - Aligned colours of clue difficulty badges to in-game colours.
    - Added close buttons to all interfaces.
- Added intial support for the Wendlewick elite scan clue.
- Added Havenhythe teleport information.
- Added all new natures sentinel outfit teleports.

## Fixes

- Added missing anagram clue for Cook.
- Added some missing teleport information.
